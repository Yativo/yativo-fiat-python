# Code of conduct

We want this project to be welcoming to everyone.

- Be respectful and kind. Disagree with ideas, not people.
- No harassment, insults, or discriminatory language.
- Assume good intent, and help newcomers.
- Keep discussions on topic.

Maintainers may remove comments, commits or contributors that break these rules.

Report problems privately to **conduct@yativo.com**. Reports are kept confidential.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
